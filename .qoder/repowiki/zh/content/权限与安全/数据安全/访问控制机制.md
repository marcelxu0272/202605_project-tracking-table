## 简介

本项目实现了基于角色的访问控制（RBAC）机制，结合前端路由守卫和后端权限验证，构建了完整的权限管理体系。系统支持多层级角色定义、数据范围控制、权限继承和审计日志等功能。

## 核心组件

### 角色管理系统

系统定义了六种核心角色，每种角色具有明确的权限边界：

| 角色 | ID | 描述 | 权限范围 |
|------|----|------|----------|
| 系统管理员 | system_admin | 全功能管理员 | 所有功能完全访问 |
| 经营管理（只读） | executive_viewer | 财务/管理层 | 只读访问，支持数据范围过滤 |
| 板块管理员 | sector_admin | 板块数据管理 | 板块内项目管理 |
| 项目经理 | pm | 项目数据填报 | 个人项目数据 |
| 板块总监 | sector_director | 审批流程 | 审批相关功能 |
| 项目群群主 | group_leader | 最终审批 | 公司级审批 |

## 详细组件分析

### 前端权限控制

前端采用Vue Router的导航守卫实现权限控制：

#### 路由守卫机制

```mermaid
flowchart TD
Start([路由导航]) --> CheckPublic{是否公开页面}
CheckPublic --> |是| AllowPublic[允许访问]
CheckPublic --> |否| CheckAuth{是否已登录}
CheckAuth --> |否| RedirectLogin[重定向到登录]
CheckAuth --> |是| GetRole[获取用户角色]
GetRole --> CheckSystem{是否系统管理员}
CheckSystem --> |是| AllowAll[允许所有操作]
CheckSystem --> |否| CheckRole[检查角色权限]
CheckRole --> CheckPM{是否项目经理}
CheckPM --> |是| CheckPMPaths{检查受限路径}
CheckPMPaths --> |包含受限路径| DenyPM[拒绝访问]
CheckPMPaths --> |不包含| AllowPM[允许访问]
CheckPM --> |否| CheckExec{是否经营管理只读}
CheckExec --> |是| CheckExecPaths{检查受限路径}
CheckExecPaths --> |包含受限路径| DenyExec[拒绝访问]
CheckExecPaths --> |不包含| AllowExec[允许访问]
CheckExec --> |否| CheckApproval{是否审批角色}
CheckApproval --> |是| CheckApprovalPaths{检查受限路径}
CheckApprovalPaths --> |包含受限路径| DenyApproval[拒绝访问]
CheckApprovalPaths --> |不包含| AllowApproval[允许访问]
CheckApproval --> |否| AllowOther[允许访问]
AllowPublic --> End([结束])
RedirectLogin --> End
DenyPM --> End
DenyExec --> End
DenyApproval --> End
AllowAll --> End
AllowPM --> End
AllowExec --> End
AllowApproval --> End
AllowOther --> End
```

## 附录

### 权限管理最佳实践

1. **最小权限原则**：为每个角色分配必要的最小权限
2. **定期审查**：定期审查用户权限和访问日志
3. **职责分离**：避免单个用户拥有过多权限
4. **审计跟踪**：启用完整的操作审计日志
5. **安全更新**：及时更新权限配置和安全补丁

### 权限继承机制

系统支持角色间的权限继承：
- 系统管理员继承所有权限
- 板块管理员继承基础权限
- 经营管理只读角色权限受限

### 权限撤销策略

```mermaid
flowchart TD
Start([权限撤销请求]) --> CheckReason{检查撤销原因}
CheckReason --> |用户离职| RevokeAll[撤销所有权限]
CheckReason --> |职责变更| PartialRevoke[撤销部分权限]
CheckReason --> |临时授权| Temporary[临时撤销]
RevokeAll --> Notify[通知相关人员]
PartialRevoke --> Notify
Temporary --> Notify
Notify --> Log[记录审计日志]
```
