# 列表 / 搜索 / 分页 / 表单 交互规范

目标是让需求、设计、开发、测试在「列表与录入」类页面上使用统一标准，减少返工与口径不一致。

以下规范建立在尼尔森十大交互原则基础上，并与本项目 `docs/DESIGN.md` 视觉体系保持一致。

## 1. 适用范围

- 列表页、台账页、管理页、审批页、主数据维护页。
- 包含筛选区 + 表格 + 分页 + 新建 / 编辑 / 详情（表单）弹窗或子页面的所有功能模块。

---

## 2. 页面整体布局

- **标准结构（从上到下）**：
  1. 页面标题 + 面包屑（可选）
  2. 筛选区（搜索栏 + 搜索按钮 + 重置按钮）
  3. 操作区（新建/导入/导出等全局操作，右对齐）
  4. 数据表格（含表头、内容行、操作列）
  5. 分页区

- **筛选区与操作区分离**：筛选条件区域与"新建/导出"等全局操作按钮不混排；操作按钮固定放在表格上方右侧。
- **筛选区折叠**：筛选项超过 2 行时，支持「展开/收起」切换；展开状态下已生效的高级条件需有可见提示（标签徽章或"已筛选 N 项"）。

---

## 3. 搜索与筛选（Search & Filter）

### 3.1 触发策略

- **非实时筛选**：修改任一筛选项后，不自动触发查询，必须点击「搜索」按钮才执行。
- **回车等效**：在文本输入框内按 Enter 等同点击「搜索」。
- **重置行为**：点击「重置」后恢复所有筛选项的默认值，并回到第 1 页，然后自动触发查询。
- ⚠️ **着重强调**：严禁对下拉框、日期选择、多选框的 `onChange` 事件直接绑定查询请求，避免频繁接口调用与误操作。

### 3.2 筛选项规范

- **默认值必须写清楚**：时间、组织、状态等筛选项的默认值必须在需求中明确（例如：默认当前年、默认全部状态）。
- **控件类型选择**：
  - 精确匹配（如编号）→ 输入框
  - 有限枚举（如状态）→ 下拉单选 / 多选
  - 时间范围 → 日期范围选择器（精确到日）；若需月份粒度，使用月份选择器
  - 模糊匹配（如姓名/项目名） → 输入框，后端 LIKE 搜索
- **筛选标签的文案**：与列表列标题保持一致，避免"筛选条件叫 A，列头叫 B"的混淆。
- **组织/部门筛选**：
  - ⚠️ **不得出现已撤销/已取消的历史部门**（除非功能明确需要查历史数据）。
  - 树形组织选择器需支持「全选本节点及子节点」。

### 3.3 高级筛选

- 高级筛选折叠时，若存在已生效的高级条件，在「展开」按钮旁展示徽章数量（例：高级筛选 `3`）。
- 展开/收起状态通过 URL query 或 sessionStorage 持久化，刷新页面后保持上次状态。

## 4. 列表展示（Table）

### 4.1 列定义

每一列在需求文档和开发阶段均须明确：

| 属性 | 说明 |
|------|------|
| 列标题 | 展示文案 |
| 字段名 | 后端字段 key |
| 数据类型 | string / number / date / enum / boolean |
| 格式 | 见 4.2 |
| 对齐方式 | 数字右对齐；文本、状态左对齐；操作列居中 |
| 是否可排序 | 是/否，及默认排序方向 |
| 宽度策略 | 固定宽/最小宽/自适应 |
| 空值展示 | 统一为 `—` |

### 4.2 数字与格式规范

- **千分位**：所有计数类 / 金额类数字默认启用千分位分隔（如 `12,345`）。
- **小数位**（同一列全局一致）：
  - 金额：保留 **2 位小数**（如 `3,871.01`）。
  - 百分比：保留 **2 位小数**（如 `94.15%`）。
  - 人天 / 工时：按业务约定，建议 **2 位** 或 **1 位**，同一字段全局一致。
  - 计数（人数、件数）：**整数**。
- **单位**：在列标题括号内显式标注（如 `合同金额（万元）`），不在每个单元格重复展示。
- **空值**：统一显示 `—`，不得展示空字符串、`null`、`0`（除非 0 有明确业务含义）。
- **日期格式**：统一 `YYYY-MM-DD`；日期时间统一 `YYYY-MM-DD HH:mm`。

### 4.3 状态列

- 状态值使用统一文案，禁止直接展示枚举值（如 `APPROVED` 应展示为「已审批」）。
- 状态使用徽章（Badge）展示，颜色语义与 `docs/DESIGN.md` 语义色保持一致：
  - 正常 / 已完成 → 绿色（`#166534` 文字 / `#dcfce7` 背景）
  - 待处理 / 进行中 → 橙色或品牌色
  - 异常 / 已驳回 → 红色（`#ef4444`）
  - 已停用 / 已取消 → 灰色
- ⚠️ **颜色不可作为唯一识别方式**，必须同时有文字标签。

### 4.4 操作列

- 操作按钮按**风险与频率**排序：查看 → 编辑 → 其他低风险 → 高风险操作（删除、作废）。
- **高风险操作（删除/作废）必须二次确认**：使用 Popconfirm 或确认弹窗，明确说明操作影响（例如：「确认删除后不可恢复」）。
- 操作列宽度固定，不随内容宽度变化。
- 按钮超过 3 个时，折叠为「更多」下拉菜单。

### 4.5 批量操作

- 勾选后，表格顶部出现批量操作工具栏，显示「已选 N 条」。
- 批量操作按钮仅在有选中项时激活。
- 跨分页批量：需明确是否支持跨页选择，若支持需在 UI 上给出明确提示。
- 批量高风险操作同样需要二次确认，确认文案中包含条数（例如：「确认删除已选的 5 条记录？此操作不可恢复。」）。

### 4.6 斑马纹与悬停

- 表格默认开启斑马纹（奇数行使用 `rgba(0,112,105,0.03)` 背景）。
- 行 hover 使用 `rgba(0,112,105,0.05)` 背景，提升可读性。

## 5. 分页（Pagination）

- **强制分页**：所有列表页默认分页展示，禁止无限滚动（除非明确有产品决策）。
- **默认每页 10 条**；可选项为 `10 / 20 / 50`。
- **总条数**：分页组件必须展示总条数，格式为「共 N 条」。
- **页码重置**：执行搜索或重置筛选后，页码强制回到第 1 页。
- **排序变更**：切换排序列/方向后，页码回到第 1 页，保留当前筛选条件。
- **空页兜底**：操作（删除/批量删除）导致当前页无数据时，自动请求上一页（`page - 1`，最小为 1）。
- **分页参数 URL 化**（可选但推荐）：`page`、`pageSize`、`sortBy`、`sortOrder` 写入 URL query，支持刷新保持状态与分享链接。

---

## 6. 排序（Sort）

- **单列排序为默认**：同一时间只有一列处于排序激活态。
- **排序状态可视化**：激活排序的列标题旁展示升序/降序箭头图标；未激活列的箭头仅在 hover 时出现。
- **默认排序**：每个列表必须定义默认排序字段与方向（如「创建时间 - 降序」），需求文档中写清楚。
- **排序持久性**：切换分页时保留排序状态；点击「重置」后恢复默认排序。
- ⚠️ **后端排序**：排序逻辑必须在后端执行，禁止仅对当前页前端数据排序后展示（会导致跨页排序不一致）。

---

## 7. 表单规范（Form）

### 7.1 新建与编辑的场景区分

| 场景 | 标题 | 默认值来源 | 提交按钮 |
|------|------|-----------|---------|
| 新建 | 「新建 XX」 | 预设默认值（见需求） | 「确认」/ 「提交」 |
| 编辑 | 「编辑 XX」 | 原始记录值完整回填 | 「保存」/ 「更新」 |
| 详情（只读） | 「XX 详情」 | 原始记录值 | 「关闭」 |

### 7.2 布局与控件

- **标签位置**：统一顶部对齐（label 在控件上方），不使用左对齐标签（避免长标签导致控件左移过多）。
- **控件宽度**：同一弹窗内控件宽度一致，按弹窗内容区宽度自适应。
- **分组**：字段超过 6 个时，按业务语义分组，分组标题加分隔线区隔。
- **两列布局**：弹窗内容区足够宽时（≥ 600px），非长文本字段可使用两列 Grid 布局；长文本（Textarea）、附件、说明字段独占一行。

### 7.3 必填与校验

- **必填标记**：必填字段在 label 旁展示红色 `*`，位置统一在标签左侧或右侧（全项目一致）。
- **校验时机**：
  - **失焦（blur）**：对单个字段做格式、范围轻校验（如邮箱格式、数值范围）。
  - **提交（submit）**：对全部必填项和格式做完整校验，逐字段展示错误信息。
- **错误信息**：位于对应字段控件正下方，文字颜色 `#ef4444`，不使用全局 Toast 替代字段级错误。
- **常见校验规则必须明确**：
  - 字符长度限制（最小/最大）
  - 数值范围（最小/最大，是否允许负数）
  - 日期范围（开始不得晚于结束）
  - 唯一性校验（如编号重复，需后端返回并展示在对应字段下）

### 7.4 默认值策略

- 新建场景的默认值必须在需求中逐字段定义（例如：默认状态「草稿」、默认日期「今天」）。
- 编辑场景必须将原始值完整回填，不得有字段遗漏或显示默认值。
- 下拉框默认为「请选择」占位；若有明确默认项，直接选中，不展示占位文案。

### 7.5 禁用与只读

| 状态 | 视觉表现 | 用途 |
|------|---------|------|
| `disabled` | 控件灰化，不可聚焦 | 当前场景下不允许修改且不需要提示原因 |
| `readOnly` | 外观与正常态相近，可聚焦可复制 | 仅展示值，无编辑意图 |
| 纯文本展示 | Label + 文本，无控件外框 | 详情模式 |

- ⚠️ 避免把 `readOnly` 和 `disabled` 混用；`disabled` 字段的值**不会**随表单提交，若仍需传值需手动处理。

### 7.6 提交防重与 loading

- 点击提交按钮后，按钮立即进入 `loading` 状态并禁用，避免重复提交。
- 接口返回（成功或失败）后恢复按钮可用状态。
- 提交过程中弹窗不可关闭（禁用 ESC 与点击遮罩关闭）。

### 7.7 离开保护

- 表单内容被修改（与初始值有差异）时，关闭弹窗或路由离开触发二次确认：「有未保存的内容，确认离开？」
- 提交成功后自动关闭，不触发离开保护。

## 8. 弹窗表单（Modal Form）

- **尺寸固定**：弹窗宽度与高度固定（例如 `width: 600px`、`max-height: 80vh`），不随内容撑开。
- **结构固定**：
  - 顶部：标题栏（含关闭按钮）—— 固定不随内容滚动
  - 中部：内容区 —— 允许垂直滚动
  - 底部：操作按钮区（取消 / 确认）—— 固定不随内容滚动
- **页面整体滚动**：弹窗打开时禁用页面 body 滚动，关闭后恢复。
- **按钮顺序**：主操作（确认/保存）在右侧，次操作（取消）在左侧，符合用户操作习惯。
- **超长表单**：字段超过一屏时，内容区滚动；不使用多 Tab 标签页（特殊业务需要除外，需产品说明）。

## 9. 状态与反馈

### 9.1 加载态

- **首次加载**：表格区域使用骨架屏（Skeleton）或统一 loading spinner 占位，不展示空表格。
- **分页/排序/筛选刷新**：在原有数据上叠加 loading 遮罩，避免表格内容突然消失。

### 9.2 空态

区分以下两种情况，文案与图示不同：

| 情况 | 展示文案示例 |
|------|------------|
| 筛选结果为空 | 「未找到符合条件的数据，请调整筛选条件后重试」 |
| 无任何数据（初始态） | 「暂无数据，点击「新建」添加第一条记录」 |
| 无权限 / 无数据范围 | 「您暂无查看该数据的权限，请联系管理员」 |

- ⚠️ 不得将"无权限"场景展示为"无数据"，避免用户误以为系统问题。

### 9.3 操作成功反馈

- **新建/编辑成功**：Toast 提示「保存成功」，弹窗关闭，列表刷新（回到第 1 页或保留当前页，由需求决定）。
- **删除成功**：Toast 提示「已删除」，列表局部刷新（当前页 item 减少，触发空页兜底逻辑）。
- **批量操作成功**：Toast 提示「已成功处理 N 条」。

### 9.4 操作失败反馈

- 错误提示需说明**原因**与**建议动作**，不仅展示「操作失败」。
- 字段级错误（如编号重复）在字段下方展示，不使用 Toast 替代。
- 接口超时 / 网络错误：展示统一错误提示，提供「重试」按钮。

## 10. 导出（Export）

- 导出前需明确导出范围，在 UI 上给出选项或在交互上隐式确定：
  - **当前筛选条件下的全部数据**（最常见）
  - **当前页数据**
  - **已选中的 N 条**
- 导出数量较大时（例如 > 1000 条）使用异步任务，给出进度反馈或通知。
- 导出文件格式默认 Excel（`.xlsx`），文件名包含功能名称 + 导出时间戳（例如 `人员列表_20260428.xlsx`）。
- 导出列的标题和格式与列表列保持一致（单位、小数位、日期格式）。

## 11. 数据与接口契约（前后端协同）

### 11.1 查询接口（Request）

```typescript
// 标准列表查询参数
interface ListQuery {
  page: number;        // 从 1 开始
  pageSize: number;    // 默认 10
  sortBy?: string;     // 排序字段名
  sortOrder?: 'asc' | 'desc';
  filters?: Record<string, unknown>; // 各筛选条件
}
```

### 11.2 查询响应（Response）

```typescript
// 标准列表响应结构
interface ListResponse<T> {
  items: T[];
  total: number;   // 满足筛选条件的总条数（用于分页计算）
  page: number;
  pageSize: number;
}
```

### 11.3 其他约定

- **枚举字段**：前后端使用一致的枚举 key，前端维护统一的枚举映射表，不在组件内硬编码中文文案。
- **时间字段**：统一 ISO 8601 字符串（`YYYY-MM-DDTHH:mm:ssZ`），前端负责格式化显示。
- **导出接口**：独立于查询接口；接受与查询接口相同的 `filters` 参数，确保导出内容与当前筛选一致。
- **软删除**：若采用软删除，后端默认过滤已删除数据，无需前端传参；如需查询已删除数据，使用独立参数（如 `includeDeleted: true`）。

## 12. 交付清单（PRD / 设计稿至少包含）

- **筛选区**：字段列表（名称、控件类型、默认值、是否必填、是否联动）。
- **列表列**：列清单（标题、字段、类型、格式、单位、对齐、排序、空值处理、操作）。
- **分页**：默认每页条数、页码重置规则、总条数展示位置。
- **排序**：可排序列清单、默认排序字段与方向。
- **表单字段**：新建/编辑两套字段清单（必填、校验规则、默认值、只读/禁用条件）。
- **状态流转**：各状态的允许操作（能编辑/删除/审批等）。
- **异常流程**：空态、加载态、无权限、网络错误的处理方案。
- **导出**：是否需要、范围、文件名格式、异步或同步。
