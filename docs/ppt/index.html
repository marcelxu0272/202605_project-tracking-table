角色矩阵 · Roles
06 / 17
Who Does What

6 个角色，各司其职

项目经理
填报本人管辖项目的产值、进度、WIP 分析。每月一次提交，提交后锁定不可再改。
板块管理员
汇总本板块全部项目经理的数据，核查修正后提交审批，是数据质量的守门人。
板块总监
只读审阅本板块全部数据，通过或驳回。数据有误只能退回，不能直接修改。
项目群群主
总监通过后的终审角色，逻辑与总监相同。各板块审批独立并行，互不等待。
系统管理员
系统配置、锁定/解锁、公司归档、审计日志。唯一能访问管理设置和全量编辑的角色。
经营管理（只读）
按权限范围（全公司/板块/项目群）只读查阅项目追踪表，无编辑、无审批。

模块一 · Data Entry
09 / 17
Module 01 · 在线填报

类 Excel 在线表格

Core Feature
83 列完整字段
与原 Excel 字段字典一一对应。列字母 A-CQ 与公式引用保持一致，冻结窗格保留项目识别关键列。
Auto Save
自动保存 + 手动同步
单元格编辑失焦后自动保存，无需手动点击。工具栏「保存」按钮触发全表同步。
Import / Export
Excel 导入导出
支持下载模板、上传导入。导入按项目号合并，仅覆盖当前角色可编辑字段。导出保留千分位和日期格式。
Detail Drawer
项目详情抽屉
点击项目号打开右侧抽屉，展示预警信息、可编辑字段、工时统计、成本中心数据等辅助参考。
关键注意点：填报页仅展示在线表格，没有传统 HTML 表格。视图筛选支持「全部/新增/有变更/预警」四种模式。

模块二 · Approval

Module 02 · 审批流程

四级审批，分板块并行

PM 提交
每月一次提交机会，提交后锁定不可再编辑，需联系板块管理员修正。
STEP 01
板块汇总
管理员查看全板块 PM 数据，核查修正后「提交审批」生成 Draft 快照。
STEP 02
总监初审
板块总监只读审阅。通过则推进，驳回则退回管理员修改并重新提交。
STEP 03
群主复审
逻辑与总监相同。各板块审批独立并行，互不等待。
STEP 04
公司归档
系统管理员在锁定期内「提交归档」，生成全公司 J 版快照作为下月基准。
FINAL
审批角色只能「通过」或「驳回」，不能直接修改数据。有误必须退回板块管理员修正。

Module 03 · 版本快照

I · D · J
三类快照

快照是系统在关键节点对数据的存档，只增不减，任何历史快照可随时只读预览。

Baseline 是判断"本月相对上月有无变化"的基准。每次 J 版归档后自动更新为最新 J 版。
— 变更对比的核心机制

I 版

D Version · Draft
D 版

J Version · Archive
J 版

模块四 · Change Tracking
12 / 17
Module 04 · 变更追踪

让每一次变动可见

审计日志
任何数据的增删改均自动记录：操作人、时间、项目、字段、原值、新值。仅系统管理员可访问审计日志页。
变更批注
变更单元格自动附加批注：「PM：0 → 100」。多角色修改同一格按序堆叠，不覆盖前一条记录。
存量预警
R 列（存量开票额）或 S 列（存量合同额）为负时红底红字预警。S < 0 阻断提交，R < 0 仅展示不阻断。

模块六 · System Admin
14 / 17
Module 06 · 系统管理

配置、锁定与报告线

表头配置
维护 83 列字段字典的表头中文名。保存后填报页即时更新，无需刷新浏览器。仅系统管理员可访问。
审批人员
按板块维护三类审批链路：板块管理员、板块审批、项目群审批。若管理员兼任总监，系统自动跳过该审批节点。
填报周期
配置报告月、提醒日、锁定日、解禁日。支持手动「立即锁定/解除锁定」，动作全程审计。
Report Lines
填报管理（报告线）
以「报告线」为核心数据单元，每条对应一个板块在一个月度内的填报实例。支持分发列配置、流转轨迹查看、逾期自动完结。
Lock Control
锁定与解锁
两种状态：开放/锁定。锁定日到达自动锁定；解锁默认关闭自动，需管理员手动操作。锁定期仅系统管理员可编辑。

15 / 17
Module 07 · 预警体系

四类预警，两级管控

Type A
R < 0
存量开票额为负：累计开票超过合同额。仅预警展示，不阻断提交。
Type B
S < 0
存量合同额为负：累计完成超过合同额。实时拦截编辑，阻断提交。
Type C
WIP-C
有完成额无工时：当月填报了产值但工时系统无记录。
Type D
WIP-D
有工时无完成额：工时系统有记录但未填报产值。
全局预警抽屉
系统管理员专属。聚合全公司所有项目的活跃预警，支持搜索、筛选、分页。点击预警卡片可直达项目详情。
手动永久忽略
系统管理员可对确认无需处理的预警执行永久忽略。跨月生效，即使条件在未来月份仍满足也不再激活。

业务规则 · Business Rules
16 / 17
Key Rules · 开发必知

四条核心业务规则

Rule 01 · S Column
存量合同额校验
手工编辑完成额时实时拦截 S < 0；仅系统同步导致 S < 0 时自动对冲调减报告月完成额。提交时兜底校验全部项目 S ≥ 0。已完成额加未来月份预测不得超过总合同额。
Rule 02 · WIP
WIP 催开票闭环
AL「WIP（催开票）」非零时，必须填写「WIP形成原因」和「高风险WIP」。WIP 归零时系统自动清空相关分析字段，避免过期内容残留。
Rule 03 · Early Report
提前申报产值
未签署合同但已开展工作的项目，经审批后可进入追踪表。合同签署后系统自动更新状态。未审批的未签署项目不可见。
Rule 04 · Year End
动态年份与跨年
字段名使用相对年份（"截止上一年底"而非"2025年底"）。跨年时全部项目自动标记为"旧项目"，当年调整值由 CRB 重新累计。
