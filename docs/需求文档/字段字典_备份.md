# 项目执行追踪详细数据 — 字段字典

> **最后更新：** 2026-05-18  
> **报告标题：** 项目执行月度报告 Project Execution Monthly Report

---

## 数据来源/类型 说明 (Legend)

在详细列表前，先了解字段的 3 种核心来源类型，这将直接决定系统交互设计：

| 类型           | 说明                            | 线上化交互方式                                     | 示例                           |
| :------------- | :------------------------------ | :------------------------------------------------- | :----------------------------- |
| **📥 系统同步** | 来自 CRB 等外部系统             | **只读/自动拉取**，不可人工修改，确保数据权威性    | 项目名称、合同额、税率         |
| **✏️ 手工填报** | 需要用户（PM/管理员）录入的数据 | **可编辑**，支持在线修改或 Excel 导入；含下拉枚举字段 | 月度产值、开票回款、WIP 原因   |
| **🧮 自动计算** | 根据其他字段公式计算得出的数据  | **只读/动态展示**，前端/后端实时计算，不可手动干预 | 不含税金额、WIP 金额、始累汇总 |

## 一、合同签署、进展（L ~ M 列）

| 列   | 字段名       | 数据类型 | **来源/类型**  | 计算逻辑 / 说明                                 |
| ---- | ------------ | -------- | -------------- | ----------------------------------------------- |
| L    | 合同是否签署 | 分类     | **🧮 逻辑判断** | **系统自动判定**：取自 CRB 合同状态。若 CRB 状态为“已确认”则自动显示“已签署”，否则显示“未签署”。<br>**准入逻辑**：未签署项目需通过“提前申报产值”审批后才会出现在追踪表中。 |
| M    | 项目实施进展 | 分类     | **✏️ 手工填报** | `进行中`、`已完成` 等，反映项目当前实际物理状态 |

## 二、合同额（N ~ Q 列）

| 列    | 字段名             | 数据类型 | **来源/类型**    | 计算逻辑 / 说明                        |
| ----- | ------------------ | -------- | ---------------- | -------------------------------------- |
| N     | 截止上一年底合同额 | 金额     | **📥 系统同步** | **系统锁定基准**：每年 1 月 1 日自动封存上一年度的期末 CRB 数据。后台数据库永久记录历年快照，前端只读，不可更改。 |
| O     | 当年调整值         | 金额     | **🧮 自动计算** | **`=P-N`**（总合同额 - 截止上一年底合同额）。 |
| **P** | **总合同额**       | 金额     | **📥 系统同步** | **CRB 动态取数**：未签署项目取 **CRB1** 合同额；签署后（状态变为“已确认”）自动切换取 **CRB3** 合同额。前端不可修改。 |
| **Q** | **不含税总合同额** | 金额     | **🧮 自动计算**   | **`=P/(1+Y)`**                         |

| ----- | ----------------- | -------- | -------------- | --------------- |
| **R** | **总合同额-开票** | 金额     | **🧮 自动计算** | **`=P-AC`**     |
| **S** | **总合同额-完成** | 金额     | **🧮 自动计算** | **`=P-U`**      |

## 四、始累完成合同额情况（T ~ V 列）

| 列    | 字段名                 | 数据类型 | **来源/类型**    | 计算逻辑 / 说明                   |
| ----- | ---------------------- | -------- | ---------------- | --------------------------------- |
| T     | 截止上一年底始累完成 | 金额     | **📥 系统同步** | **系统自动翻转**：每年 1 月 1 日抓取上一年度末累计完成值。后台保留每年历史值。 |
| **U** | **项目始累完成合同额** | 金额     | **🧮 自动计算**   | **`=T+X`**（上一年底始累 + 今年累计） |
| **V** | **当年期初存量**       | 金额     | **🧮 自动计算**   | **`=N-T`** |

## 五、项目年度完成合同额申报情况（W ~ Z 列）

| 列    | 字段名               | 数据类型 | **来源/类型**  | 计算逻辑 / 说明                         |
| ----- | -------------------- | -------- | -------------- | --------------------------------------- |
| **W** | **报告当期完成**     | 金额     | **🧮 动态映射** | **`=AZ`**（指向当月填报列，随月份变化） |
| **X** | **本年度完成**       | 金额     | **🧮 自动计算** | **`=SUM(1月~当月)`**                    |
| Y     | 税率                 | 比率     | **📥 系统同步** | 取自 CRB 合同条款，6%/9%/13%            |
| **Z** | **不含税本年度完成** | 金额     | **🧮 自动计算** | **`=X/(1+Y)`**                          |

## 六、项目开票回款情况（AA ~ AF 列）

| 列     | 字段名           | 数据类型 | **来源/类型**    | 计算逻辑 / 说明          |
| ------ | ---------------- | -------- | ---------------- | ------------------------ |
| AA     | 截止上一年底累计开票 | 金额 | **🧮 逻辑取值** | **系统自动翻转**：每年 1 月 1 日抓取上一年度末累计开票。后台保留每年历史值。 |
| **AB** | **本年累计开票**     | 金额 | **🧮 自动计算** | **`=SUM(1月~当月开票)`** |
| **AC** | **项目始累开票**     | 金额 | **🧮 自动计算** | **`=AA+AB`** |
| AD     | 截止上一年底累计回款 | 金额 | **🧮 逻辑取值** | **系统自动翻转**：每年 1 月 1 日抓取上一年度末累计回款。后台保留每年历史值。 |
| **AE** | **本年累计回款** | 金额     | **🧮 自动计算**   | **`=SUM(1月~当月回款)`** |
| **AF** | **项目始累回款** | 金额     | **🧮 自动计算**   | **`=AD+AE`**             |

| ------ | ---------------------- | -------- | -------------- | ------------------------------------------------ |

## 📊 线上化开发指南

### 1. 字段权限控制矩阵 (RBAC 基础)

系统权限将基于上述"类型"进行映射：

*   **📥 系统同步**：对所有人 **只读 (Read-Only)**。
*   **🧮 自动计算**：对所有人 **只读 (Read-Only)**，由系统实时渲染结果。
*   **✏️ 手工填报**（含带枚举下拉的字段，如 WIP 形成原因）：
    *   **填报期**：项目经理/板块管理员 **可读写 (Write)**。
    *   **非填报期/锁定后**：变为 **只读 (Read-Only)**。
    *   **管理员特权**：系统管理员可覆盖。

### 2. 前端交互建议

*   **视觉区分**：
    *   可编辑字段使用白色背景/输入框样式。
    *   计算字段和系统取值字段使用灰色背景，鼠标悬停显示数据来源（如 "Source: CRB" 或 "Calc: N+O"）。
*   **实时计算**：
    *   当用户修改 `AV~BG` (月度完成额)、`BH~CE` (月度开票/回款) 等手工填报字段时，相关的计算字段 (`X`, `U`, `AB`, `AE`, `AG` 等) 必须 **毫秒级联动刷新**，不需要刷新页面。
